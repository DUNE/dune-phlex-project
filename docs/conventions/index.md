# Conventions

Phlex leaves units, timestamp formats, and Python usage patterns to experiments. The proposals below have no ratification decision recorded here.

- [Units (CLHEP)](units.md): use the CLHEP system of units with `hep-units`, `boost-config`, and `hep-config`; proposed for the Phlex Adoption WG in September 2026.
- [Timestamps](timestamps.md): shell helpers for UTC, ISO 8601 timestamps in job scripts.
- [Python](python.md): a working session on data-product formats and library resource use; the session date and resulting conventions remain open.

Adoption decisions and links to the approved proposals should be added to each page when available.
